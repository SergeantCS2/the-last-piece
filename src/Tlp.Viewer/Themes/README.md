# Viewer looks

A look is two parts:

- **Tokens**, a `ResourceDictionary` that sets the `Tlp*` keys: colours and brushes, fonts, sizes,
  corners, glows, `TlpVariant` (Light, Dark, or Default to follow Windows) and the keys that
  Avalonia's Fluent controls read (text boxes, combo boxes, check boxes, scroll bars). The default
  look's tokens are hand-written in `Default.axaml`. The others are generated by
  `tools/theme-tokens.py` from a small palette (`python3 tools/theme-tokens.py` rewrites the
  `*Tokens.axaml` files).
- **Styles**, a `Styles` file with whole control templates, so a look can change shape and add
  decoration, not just colour. The window has named parts a look can restyle:
  `ContentControl.backdrop` and `.overlay` (behind and over everything, never clickable),
  `.kicker`, `.brand` and `.side` (the header), `HeaderedContentControl.panel` (the cards), the
  settings `Expander`, `ContentControl.statusbar` and `Border.item` (a file row).

`Styles.axaml` is the shared base. `ThemeManager.cs` lists the looks and swaps tokens and styles at
run time, so picking a look in Settings previews it straight away; Save settings keeps it.

| Look | Idea | Fonts |
|---|---|---|
| Default | Plain on purpose: system-style colours, standard blue accent, no decor or motion; only the shared styles | Inter |
| Warm | Clean, warm neutral cards with a red accent and a clock; follows Windows light or dark | Space Grotesk, Inter |
| Phosphor Amber / Green | Retro-future terminal: CRT glass, scanlines, glow, bracket buttons, blinking cursor | VT323, IBM Plex Mono |
| Breach | Cyberpunk hacking HUD: chamfered panels, glitch title, hazard stripes | Chakra Petch, Rajdhani, Share Tech Mono |
| Outrun | Synthwave: neon sign title, striped sun, perspective grid, VHS line | Monoton, Exo 2 |

Motion (glow bands, glitch, flicker, twinkling stars) pauses while the window isn't active, to save
power, and stays off when the viewer unticks "Animate the look" in Settings. Both work through a
`still` class on the decorated parts, so a look's animations should all sit under `:not(.still)`. Shapes the looks need (cut corners, corner marks, the CRT bezel, the clock) are small
controls in `Decor/Shapes.cs`.

Rules for every look: our own colours and art, and fonts under the SIL Open Font License (texts in
`Assets/Fonts/licenses`). Looks may evoke a genre but use no artwork, logos, fonts or names from
any game or film.

Checks: the app's self-test (`--self-test DIR`) fails if a look misses a key or a font falls back
to a system font, and saves a picture of each look. Those pictures skip drop shadows and glows,
so for real pictures run `TheLastPiece --showcase "Breach" [settings] [dark]`, which opens the app
with a sample night in that look, and screenshot the window.
